# 个人知识管理系统

当前版本：1.0.1

这是一个采用 Spring Boot 2.7、Vue 3 与 MySQL 构建的前后端分离 Web 系统。仓库只包含系统源码、数据库结构脚本和部署运行文档，不包含论文原件、构建缓存、本地密钥或演示用户数据。

## 目录

- `backend/`：Spring Boot 后端，默认端口 `8088`
- `frontend/`：Vue 3 + Vite 前端，开发端口 `5173`
- `database/init.sql`：MySQL 数据库结构初始化脚本
- `docs/系统部署与运行指南.md`：完整的本地运行与生产部署说明

## 开始使用

请阅读 [系统部署与运行指南](docs/系统部署与运行指南.md)。首次启动后端前必须通过环境变量设置数据库密码、JWT 密钥和初始管理员密码。
